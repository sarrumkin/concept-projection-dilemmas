# Отчёт автора 0

Данные сгенерированы с помощью ИИ по назначенным триплетам и определениям конфликтов. Для каждой из 60 записей добавлены три самостоятельных англоязычных сценария A, B и C: A и B используют один и тот же конфликт, C использует `negative_conflict` и сохраняет тему `anchor_topic`.

Проверки выполнены автоматически: 60 записей; 180 абзацев; все назначенные поля сохранены; все абзацы содержат 40–70 слов; все заканчиваются знаком вопроса; все тексты уникальны; кириллица отсутствует.

Ограничение: проверка семантической границы конфликтов выполнена по исходным определениям и ручному просмотру формулировок, без внешней разметки или embedding-метрик.
